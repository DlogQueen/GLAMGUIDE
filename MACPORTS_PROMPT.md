### **INSTALL INSTRUCTIONS (For MacPorts):**

```
═══════════════════════════════════════════════════════
🍎 INSTALL GLAM GUIDE AI VIA MACPORTS
═══════════════════════════════════════════════════════

QUICK INSTALL:
━━━━━━━━━━━━━━
sudo port install glam-guide-ai

FIRST TIME SETUP:
━━━━━━━━━━━━━━━━━
1. Install MacPorts (if not installed):
   https://www.macports.org/install.php

2. Update ports:
   sudo port selfupdate

3. Install Glam Guide AI:
   sudo port install glam-guide-ai

4. Launch:
   /Applications/Glam\ Guide\ AI.app

OR via terminal:
   open -a "Glam Guide AI"

UPGRADE:
━━━━━━━━
sudo port upgrade glam-guide-ai

UNINSTALL:
━━━━━━━━━━
sudo port uninstall glam-guide-ai

TROUBLESHOOTING:
━━━━━━━━━━━━━━━━
• App won't open: Check macOS Gatekeeper settings
• Camera not working: Grant camera permissions in System Preferences
• AR laggy: Close other apps, needs GPU access

═══════════════════════════════════════════════════════
```
